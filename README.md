## Organization

Each USACO problem lives at `USACO/DIVISION/YEAR-contest-pNUMBER-problem-name/`, with its source code and a README retaining the original IDE title and public problem link. Distinct saved versions remain separate files.

The 2026-10-24 USACO Guide IDE import includes **178 saved source files for 176 problems**. See the [division indexes](./USACO/) and [import manifest](./USACO/import-manifest.json) for the complete inventory and checksums. Archived work is not automatically a verified or accepted solution.

For future work, follow the [USACO organization rules](./USACO/#future-additions). Problems from Codeforces, AtCoder, CSES, and other platforms belong under `Other/`; reusable templates belong under `misc/`.
