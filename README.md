# problemset

A storage repository for competitive programming problem solutions, organized by category.

## Structure

```
problemset/
├── USACO/          # USA Computing Olympiad problems
│   ├── Bronze/     # Entry-level division
│   ├── Silver/     # Intermediate-level division
│   ├── Gold/       # Advanced-level division
│   └── Platinum/   # Expert-level division
└── Other/          # Problems from other platforms (Codeforces, AtCoder, LeetCode, etc.)
```

## About USACO

The USA Computing Olympiad (USACO) is a computer programming competition for pre-college students. Problems are divided into four divisions based on difficulty:
- **Bronze**: Entry level, basic programming and simple algorithms
- **Silver**: Intermediate level, graph algorithms and data structures
- **Gold**: Advanced level, dynamic programming and complex algorithms
- **Platinum**: Expert level, advanced algorithms and data structures

## Contributing

Each problem solution should be in its own directory with:
- Solution code (`.cpp`, `.py`, `.java`, or other language)
- `README.md` with problem description, approach, and complexity analysis
- Optional: sample input/output files
