# Other Problems

This directory contains solutions to competitive programming problems from sources other than USACO.

## Potential Sources

- Codeforces
- AtCoder
- LeetCode
- TopCoder
- Project Euler
- Google Code Jam
- Other online judges and competitions

## Organization

Organize problems by platform/source:
```
Other/
  ├── Codeforces/
  ├── AtCoder/
  ├── LeetCode/
  └── ...
```

Or by topic/algorithm type:
```
Other/
  ├── Dynamic-Programming/
  ├── Graph-Algorithms/
  ├── Data-Structures/
  └── ...
```

Each problem should have:
```
problem-name/
  ├── solution.cpp (or your preferred language)
  ├── README.md (problem description/link/notes)
  └── input.txt (optional: sample test cases)
```
