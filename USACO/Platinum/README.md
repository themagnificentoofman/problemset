# Platinum Division

This directory contains solutions to USACO Platinum division problems.

Platinum is the highest division of USACO, typically covering:
- Advanced dynamic programming
- Complex graph algorithms
- Advanced data structures (heavy-light decomposition, persistent data structures)
- String algorithms (suffix arrays, KMP)
- Advanced mathematics and number theory

## Adding a Problem

Create a new directory for each problem:
```
problem-name/
  ├── solution.cpp (or your preferred language)
  ├── README.md (problem description/notes)
  └── input.txt (optional: sample test cases)
```
