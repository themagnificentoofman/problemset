# Silver Division

This directory contains solutions to USACO Silver division problems.

Silver division typically covers:
- Graph algorithms (DFS, BFS)
- Greedy algorithms
- More complex data structures (sets, maps)
- Binary search
- Prefix sums

## Adding a Problem

Create a new directory for each problem:
```
problem-name/
  ├── solution.cpp (or your preferred language)
  ├── README.md (problem description/notes)
  └── input.txt (optional: sample test cases)
```
