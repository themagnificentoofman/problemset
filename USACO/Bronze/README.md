# Bronze Division

This directory contains solutions to USACO Bronze division problems.

Bronze is the entry-level division of USACO, typically covering:
- Basic programming concepts
- Simple algorithms
- Brute force approaches
- Basic data structures

## Adding a Problem

Create a new directory for each problem:
```
problem-name/
  ├── solution.cpp (or your preferred language)
  ├── README.md (problem description/notes)
  └── input.txt (optional: sample test cases)
```
