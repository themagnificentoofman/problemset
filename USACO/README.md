## Organization

For example: `Gold/2018-us-open-p3-talent-show/solution.cpp`.

Each problem directory contains the original saved source and a README with its exact IDE title and USACO problem link. Multiple workspaces for the same problem are kept as separate source versions. The [import manifest](./import-manifest.json) records every source file, its original title, creation date, size, and SHA-256 checksum.

## Import scope and status

The 2026-10-24 import contains all 178 workspaces with titles matching `YEAR CONTEST DIVISION: NUMBER. PROBLEM NAME`, representing 176 unique problems. Hidden entries were included in the inventory check. Custom-named workspaces and templates fall outside this import's title filter.

Source text is preserved as saved. This is an archive of work; correctness, completeness, and judge acceptance have not been assessed. Live collaborative IDE workspace links are omitted from this public repository.

## Future additions

1. Put each USACO problem under its division using `YEAR-contest-pNUMBER-problem-name/`.
2. Save code as `solution.cpp` (or the corresponding language extension) and record its original title and public problem link in a README.
3. Preserve distinct saved attempts as separate versions; compare content before replacing a file.
4. Update the division index. Record acceptance only when verified from judge results.

Problems from other platforms belong under [Other](../Other/).
