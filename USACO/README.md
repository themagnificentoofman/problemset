# USACO Problems

This directory contains solutions to USA Computing Olympiad (USACO) problems organized by division.

## Structure

- **Bronze/**: Entry-level problems
- **Silver/**: Intermediate-level problems
- **Gold/**: Advanced-level problems
- **Platinum/**: Expert-level problems

## Organization

Each problem should be in its own subdirectory within the appropriate division, named according to the problem name or contest.

Example structure:
```
Bronze/
  └── problem-name/
      ├── solution.cpp (or .py, .java, etc.)
      ├── input.txt (sample input)
      └── README.md (problem description/notes)
```
