# Gold Division

This directory contains solutions to USACO Gold division problems.

Gold division typically covers:
- Advanced graph algorithms (shortest paths, minimum spanning trees)
- Dynamic programming
- Advanced data structures (segment trees, BIT)
- Number theory
- Computational geometry basics

## Adding a Problem

Create a new directory for each problem:
```
problem-name/
  ├── solution.cpp (or your preferred language)
  ├── README.md (problem description/notes)
  └── input.txt (optional: sample test cases)
```
